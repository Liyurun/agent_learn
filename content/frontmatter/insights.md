      <h2 class="chap-title"><span class="kicker">00D</span>大牛观点：站在巨人的肩膀上</h2>
      <p class="cjk">技术细节会过时，但顶尖研究者的<mark class="key">思维方式</mark>不会。这一节把 Karpathy、Andrew Ng、Anthropic、Harrison Chase、Lilian Weng、姚顺雨、Cognition（Devin）、Dex Horthy、Hamel Husain、Noam Brown 等人对 Agent 最凝练的判断收拢成一面"金句墙"——每条都附上出处与<strong>可直接用于面试的表达</strong>。读观点时别只记结论，更要体会他们"为什么这么想"。</p>
      <div class="callout tip">
        <span class="label">怎么用这一节</span>
        <span class="cjk">先按主题筛选（如"极简优先""评估为王""架构取舍"），挑 2–3 条你最认同的，用自己的话复述一遍，并想清楚"它如何改变我做 Agent 的方式"。把大牛观点<strong>内化成判断</strong>，而不是背成口号——这正是面试官想听到的深度。</span>
      </div>
      <div class="callout warn">
        <span class="label">观点交锋 · 多 Agent 之争</span>
        <span class="cjk">Cognition 的 <strong>Walden Yan</strong> 主张<em>"别急着上多 Agent"</em>——动作背后的隐含决策一冲突结果就崩，默认应走单线程线性架构；而 <strong>Anthropic</strong> 用多 Agent 研究系统把评测拉高 90%，代价是约 <strong>15× token</strong>。两者其实不矛盾：<mark class="key">多 Agent 不是更高级，而是一种昂贵且有前提的权衡</mark>——只有当任务能拆成独立并行子任务、且价值高到能覆盖成本时才划算。能把这场"分歧"讲成"同一枚硬币的两面"，是面试里的高分表达。</span>
      </div>
