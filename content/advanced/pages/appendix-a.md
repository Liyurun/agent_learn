## A.1 权威指南与官方工程博客（一手，⭐必看）

这些是理解 Agent 设计理念的一手权威资料，出自模型厂商与核心工程团队，观点最常被面试引用，建议反复读。

- [ ] **⭐ Anthropic《Building Effective Agents》** [来源](https://www.anthropic.com/engineering/building-effective-agents)
  - 一句话价值：把 Agent 生态拆成"工作流(Workflow) vs 智能体(Agent)"两类，并给出五种可组合构建块（提示链、路由、并行、编排者-工作者、评估者-优化者），是全领域的概念锚点。
  - 适合谁：所有阶段，尤其入门期建立心智、面试前重读。
  - 读法建议：第一遍通读抓两组概念，第二遍带问题读"我的需求该用工作流还是 Agent"。读完立刻用自己的话写三条"什么时候不该上 Agent"——这几乎是每场面试的开场题。避坑：别把五种模式当"必须全用"的清单，Anthropic 反复强调"能用简单方案就别加复杂度"。
- [ ] **⭐ OpenAI《A Practical Guide to Building Agents》** [来源](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf)
  - 一句话价值：从单 Agent 起步、真正需要时再引入多 Agent 编排的落地手册，讲护栏、交接(handoff)、演进节奏。
  - 适合谁：已跑通一个单 Agent Demo、开始纠结工程权衡的进阶者。
  - 读法建议：放在有单 Agent 经验之后读，否则里面的取舍没有痛点、体会不深。它和 Anthropic 措辞略有差异，不必纠结"谁的定义才对"，抓住共识（先单后多、先简后繁）即可。
- [ ] **⭐ Anthropic《Effective Context Engineering for AI Agents》** [来源](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  - 一句话价值：2026 年最值得读的一手长文之一，系统讲"上下文工程"——如何在推理时精选、维护进入上下文窗口的 token，把 prompt 工程升级为上下文治理。
  - 适合谁：做过 RAG 或长对话、开始遇到"上下文塞太多反而变差"的进阶者。
  - 读法建议：配合附录 C 的"中间迷失(Lost in the Middle)"与"上下文工程"两条术语一起看；重点抓"只放当前决策必需的信息"这条主线。
- [ ] **✅ Anthropic《Building Agents with the Claude Agent SDK》** [来源](https://www.anthropic.com/engineering/building-agents-with-the-claude-agent-sdk)
  - 一句话价值：官方给出用 Agent SDK 搭生产级 Agent 的最佳实践，含子 Agent(subagents)、工具与权限管理的实操经验。
  - 适合谁：已理解原理、准备动手搭一个真项目的进阶者。
  - 读法建议：当"工程参考"读，重点看它如何组织工具、如何拆子 Agent；具体 API 命名以官方文档当前版本为准，别照抄博客里的旧签名。
- [ ] **⭐ Model Context Protocol 官方文档** [来源](https://modelcontextprotocol.io/)
  - 一句话价值：MCP 协议的权威定义，把 N×M 的工具对接标准化成一套协议，被称为"AI 的 USB-C"。
  - 适合谁：要接工具、写 MCP Server 的进阶者。
  - 读法建议：这是查阅型资料，不必通读。按"概念 → 快速上手 → Server/Client 规范"三段跳读，先搞懂 Resources / Tools / Prompts 三原语，再照 quickstart 跑一个本地 Server。协议在演进，务必以官网当前版本为准。

> **经验**：这一档的正确打开方式是"反复读"而非"读一遍打钩"。面试官引用最多的观点几乎都出自 Anthropic 与 OpenAI 这两份指南——面试前一晚重读它们的收益，远高于临时刷题。

## A.2 系统课程与教程（⭐必看）

- [ ] **⭐ Hugging Face Agents Course** [来源](https://huggingface.co/learn/agents-course)
  - 一句话价值：免费、系统、从零到实践的主线课程，配套极简框架 smolagents，有考核。
  - 适合谁：零基础入门首选。
  - 读法建议：严格按单元推进，每单元先看概念再动手改代码，别跳过练习。边学边把练习提交到自己的 GitHub，一个月下来就是一份可展示的学习轨迹。最容易犯的错是"只看不敲"——Agent 是极度依赖手感的技能，遇报错先自己查 15 分钟再求助。
- [ ] **✅ DeepLearning.AI 系列短课** [来源](https://www.deeplearning.ai/short-courses/)
  - 一句话价值：Andrew Ng 团队的多门 Agent 主题短课（Function Calling、多 Agent、评估等），每门 1-2 小时、主题聚焦。
  - 适合谁：想按知识点专项补强的入门~进阶者。
  - 读法建议：当"专题加餐"，哪个点薄弱就选哪门，不必全刷；放在 HF 课程主线之后补单点。注意短课常用某框架的封装 API，别把"某框架的写法"误当成"Agent 的通用原理"——学完要能把它讲的做法"翻译"回底层机制（如某个封装函数本质就是一次 Function Calling）。
- [ ] **📖 NirDiamant/agents-towards-production** [来源](https://github.com/NirDiamant/agents-towards-production)
  - 一句话价值：一批生产级教程合集，覆盖编排、可观测性、护栏、部署等真实工程主题。
  - 适合谁：进阶~高级，做项目时对照查。
  - 读法建议："问题驱动"地用——当你的项目遇到"怎么加 tracing/怎么做护栏/怎么部署"时来找对应教程照做。不要从头顺读，也不要盲抄配置，要理解每步"解决的是什么生产问题"。

## A.3 开源框架与代码仓库（✅推荐，动手学习主战场）

动手学习的最佳资源，边读边跑。原则是"深挖一个胜过浅尝十个"。

- [ ] **⭐ smolagents（Hugging Face）** [来源](https://github.com/huggingface/smolagents)
  - 一句话价值：极简 Agent 框架，薄到能把核心循环从头读一遍，是拆解 Agent 本质的最佳教具。
  - 适合谁：第一个要读源码的框架，入门~进阶。
  - 读法建议：先跑通官方搜索 Agent，再打开源码找到"调用模型 → 解析动作 → 执行工具 → 回填观察"的主循环，逐行读懂。理解了这个循环，你就理解了 90% 的 Agent 框架。别急着换重框架，先在薄框架上把原理吃透。
- [ ] **✅ PydanticAI** [来源](https://github.com/pydantic/pydantic-ai)
  - 一句话价值：类型安全的生产级框架，示范"能上线的 Agent 代码长什么样"——类型约束输出、依赖注入、结构化输出。
  - 适合谁：已能徒手写 Agent 循环、想学工程化范式的进阶者。
  - 读法建议：重点看它如何用类型约束输出、如何做结构化输出与校验。类型系统上手有门槛，别被 Python 类型标注劝退，它换来的是可维护性。
- [ ] **✅ LangGraph（LangChain）** [来源](https://github.com/langchain-ai/langgraph)
  - 一句话价值：图结构编排框架，适合分支多、需回环和持久化状态的复杂流程。
  - 适合谁：做复杂/有状态工作流的进阶~高级者。
  - 读法建议：先想清楚你的流程画成图长什么样（节点是什么、边的条件是什么），再落代码。别用图框架去做本可以三行代码解决的线性流程——为用而用只会徒增复杂度。配合官方文档 [来源](https://langchain-ai.github.io/langgraph/) 与 LangChain 文档 [来源](https://docs.langchain.com/) 查概念。
- [ ] **📖 OpenAI Agents SDK** [来源](https://openai.github.io/openai-agents-python/)
  - 一句话价值：OpenAI 官方 Agent 框架，重点参考多 Agent 交接(handoff)与人在回路(Human-in-the-Loop, HITL)设计。
  - 适合谁：研究多 Agent 编排的进阶者。
  - 读法建议：当索引查，看它如何定义 Agent 间移交与上下文传递。多 Agent 是"最后的手段"，先确认单 Agent + 工具真的搞不定再上。
- [ ] **📖 Google Agent Development Kit（ADK）** [来源](https://github.com/google/adk-python)
  - 一句话价值：Google 开源的模块化 Agent 框架，把 Agent 循环、会话、记忆、回调等做成工程化组件，模型无关、部署无关。
  - 适合谁：想横向对比多家框架设计取舍、或在 Google 生态里落地的进阶者。
  - 读法建议：当"第二个对照框架"读——把它和 smolagents（极简）、LangGraph（图编排）放一起比"同一个 Agent 循环各家怎么抽象"。注意它有跨大版本的破坏性变更，务必对齐仓库当前版本的 API，别照抄旧教程。
- [ ] **✅ 官方 MCP Servers 参考实现仓库** [来源](https://github.com/modelcontextprotocol/servers)
  - 一句话价值：MCP 官方维护的一批参考 Server 实现（文件系统、数据库、检索等），是"看别人怎么把工具包成 MCP"的最佳范例库。
  - 适合谁：要动手写自己的 MCP Server、或想理解三原语如何落地的进阶者。
  - 读法建议：挑一个最简单的 Server（如文件系统）通读，照它的结构改出自己的第一个 Server；配合 MCP 官方文档的 quickstart 一起看。协议在演进，以仓库当前实现为准。
- [ ] **⭐ NirDiamant/GenAI_Agents** [来源](https://github.com/NirDiamant/GenAI_Agents)
  - 一句话价值：40+ 个文档完善的 Agent 案例 Notebook，从基础到高级，动手素材极丰富。
  - 适合谁：入门~进阶，想边跑边学。
  - 读法建议："照着跑 + 改一处"：先原样跑通一个案例，再改一个变量（换工具/换 prompt/换编排方式）观察行为变化——改比读更长记性。入门挑 3-5 个基础案例吃透即可，别贪多；跑不通先怀疑库版本与 Key 配置，而不是代码逻辑。

> **生产踩坑**：很多人收藏了几十个仓库却一个都没跑通，收藏夹变成"知识焦虑收集器"。正确做法是把 smolagents 一个框架的源码彻底读透，比 star 十个框架有用得多。

## A.4 个人技术博客与深度长文（✅推荐，建立心智模型）

体系化拆解 Agent 的高信息密度长文，适合搭知识骨架。

- [ ] **✅ Lilian Weng《LLM Powered Autonomous Agents》** [来源](https://lilianweng.github.io/posts/2023-06-23-agent/)
  - 一句话价值：把 Agent 拆成"规划 + 记忆 + 工具"三大件的经典长文，是很多课程的知识骨架。
  - 适合谁：入门~进阶，建立整体心智模型时读。
  - 读法建议：先读这篇搭骨架，做"结构化笔记"只记模块划分和关键结论，细节需要时再回查。她的博客主页 [来源](https://lilianweng.github.io/) 还有幻觉、奖励攻击等深度文，可按需扩展。
- [ ] **✅ Chip Huyen《Agents》** [来源](https://huyenchip.com/2025/01/07/agents.html)
  - 一句话价值：对 Agent 规划、工具、失败模式的深度剖析，强调规划的现实困难。
  - 适合谁：进阶，已搭好骨架、想补现实感时读。
  - 读法建议：放在 Lilian Weng 之后读（先骨架后现实感）。信息密度极高，别指望一遍读透，重点抓"失败模式"部分——那是面试深挖时的高价值素材。
- [ ] **📖 OpenAI Cookbook** [来源](https://cookbook.openai.com/)
  - 一句话价值：官方维护的可运行示例合集，覆盖 Function Calling、检索、评估等常见工程任务。
  - 适合谁：需要"能直接跑的官方范例"时查阅的进阶者。
  - 读法建议：当代码字典用，按任务名检索对应 notebook；示例里的模型名与参数会变，以你实际可用的模型为准。
- [ ] **📖 Simon Willison 博客（LLM/工具实践）** [来源](https://simonwillison.net/)
  - 一句话价值：高产的一手实践派长期观察，紧跟模型与工具链的真实变化，常有第一手上手体验与踩坑记录。
  - 适合谁：想跟进"业界这周又变了什么、某新特性到底好不好用"的所有阶段读者。
  - 读法建议：当"追新雷达"用，按标签（如 llms、agents、prompt-injection）翻，看他怎么用第一手实验去验证宣传话术——这种"自己动手验证"的态度本身值得学。它是观点性内容，结论以你自己复现为准。

> **一手 vs 二手的判断标准**：这一档偏个人观点与实践，价值在"密度高、有第一手经验"，但**不等于权威定义**。遇到与官方指南冲突时，以 A.1 的官方一手资料为准；博客更适合用来补"官方文档不会写的踩坑与直觉"。

## A.6 保持信息更新的渠道

Agent 领域变化极快，用"信息分层"避免被淹没：把渠道分成"每周必看"和"按需查"两层，只对第一层保持固定节奏。

- [ ] **每周必看** · 官方工程博客（Anthropic、OpenAI、Hugging Face）+ 你在用框架的 Release Notes。它最贴近你的实际代码，信息噪声最低，是"追新"的正确姿势。
- [ ] **按需查** · arXiv 的 cs.AI / cs.CL 新论文，用综述引用滚动跟进。每周固定 30 分钟扫标题+摘要，只标记 1-2 篇真正相关的深读，其余记个印象即可。
- [ ] **社区** · 优质的 Agent 主题 newsletter 与技术社区讨论，用问题驱动地看，不追热点。

> **判断新东西值不值得学**：只问一句"它解决了老方案解决不了的什么问题"，答不上来就先放着。Agent 领域"新名词"层出不穷，很多只是旧概念换皮。

**给"信息焦虑"的三剂解药**：

- **设上限而非求全**：给自己定"每周最多深读 2 篇"，其余只存不读。信息是无限的，注意力是有限的，读完两篇远胜收藏二十篇。
- **用产出倒逼输入**：不为"读了多少"打卡，为"跑通了什么、能讲清什么"打卡。一篇能落到代码或笔记上的资料，抵得过十篇划过去的。
- **接受"暂时不懂"**：遇到看不懂的前沿，标记后跳过，等基础更扎实再回看。多数前沿一年后要么成常识、要么被淘汰，早期死磕性价比很低。

## A.7 分级学习路线（可勾选，照着走就不迷路）

把资源按"四级路线"重新编排，每级给出目标、主线资源、里程碑产出和大致周期。你只需专注当前这一级，完成一级勾一级。

- [ ] **Level 1 · 建立心智（约 1 周）**
  - 目标：说清 Agent 是什么、和普通 LLM 调用差在哪。
  - 主线：Anthropic《Building Effective Agents》+ Lilian Weng 长文 + HF 课程前几单元。
  - 里程碑产出：一段"Agent vs Workflow"的口述 + 一张组件图。
  - 避坑：别陷入"术语背诵"，这一级目标是建立直觉，能用大白话讲明白比记住英文缩写重要。
- [ ] **Level 2 · 跑通原理（约 2 周）**
  - 目标：徒手看懂并改动一个 Agent 主循环。
  - 主线：smolagents 源码 + HF 课程动手单元 + GenAI_Agents 基础案例。
  - 里程碑产出：跑通并改造 2-3 个案例，能画出 ReAct(Reason + Act) 循环。
  - 避坑：别跳过"改代码"，只跑不改等于没学，每个案例至少改一处并观察结果。
- [ ] **Level 3 · 工程落地（约 2-3 周）**
  - 目标：做出一个能讲清架构与权衡的项目。
  - 主线：PydanticAI / LangGraph + agents-towards-production + MCP 文档。
  - 里程碑产出：一个多工具 + 记忆 + 可观测的作品集项目。
  - 避坑：别追求"技术全家桶"，一个想清楚的项目 > 三个半成品，宁可功能少也要把"为什么这么设计"讲透。
- [ ] **Level 4 · 持续跟进（长期）**
  - 目标：跟得上领域变化、面试前能快速热身。
  - 主线：官方博客 + Release Notes + 综述索引 + 附录 B/C。
  - 里程碑产出：稳定的信息跟进习惯 + 面试知识地图。
  - 避坑：别被 FOMO 绑架，守住核心、按需扩展才是可持续节奏。

> **面试会怎么问**：面试官常问"你平时怎么学 Agent、怎么跟进新进展"，这题考的是学习方法论。用上面的分级路线回答——"我按建立心智、跑通原理、工程落地、持续跟进四步走，主线是 Anthropic 指南、smolagents 源码和生产级教程"——比笼统说"我看了很多资料"专业得多。

## A.8 按目标反查资源（哪种需求看哪份）

带着一个具体目的进来，直接查该看哪份，省去在清单里翻找的时间。

| 你现在想解决的问题 | 首选资源 | 补充资源 | 一句话提示 |

**几个高频疑问的直接回答：**

- **"资料这么多，先看哪个？"**——只能选一份就选 Anthropic《Building Effective Agents》；只能选一个动手项目就把 smolagents 源码读透。二者组合覆盖大部分入门需求。
- **"要不要买付费课/书？"**——本清单已覆盖从入门到工程落地。把免费资源吃透，收益远大于囤一堆没看的付费课。
- **"英文资料读不动怎么办？"**——先读中文讲解（如本书正文）建立概念，再回看英文原文的核心段落（Abstract、结论、关键图表），只挑最关键的读。
- **"边学边找工作还是学完再找？"**——建议边学边投。第 3 周有作品集后就可开始投递，面试暴露的短板会反过来精准指导你补哪里，真实面试本身就是最好的检验。
- **"框架更新太快，学的会不会很快过时？"**——底层原理（ReAct 循环、Function Calling 机制、记忆与检索、护栏与评估）非常稳定，会变的只是具体框架的 API。把精力优先投在原理和一个框架的源码上，换框架时你只需重新查文档。
- **"要不要读全部这些资料？"**——不要。这份总表是"地图"不是"作业"。绝大多数人真正吃透的就是 Anthropic 指南 + 一个框架源码 + 几个动手案例，其余按 A.8 的"按目标反查"随用随查即可。收藏而不读只会加重焦虑。
- **"论文和工程博客先看哪个？"**——先工程博客后论文。博客（Anthropic/OpenAI）讲"怎么落地、如何权衡"，离你的代码最近；论文（附录 B）讲"某个机制为什么成立"，是深挖时的弹药。入门先靠博客建立工程直觉，面试深挖再回论文补方法细节。

## A.9 怎么判断一份资料值不值得读（避坑清单）

Agent 领域资料泛滥、真假混杂，学会筛比多读更重要。拿到一份资料先过一遍这份清单，能滤掉大量低质内容：

- [ ] **来源可核验吗**：是官方博客/论文/官方仓库（一手），还是转述二手？二手可当入口，但关键结论要回到一手核对。本附录所有链接都是可公开核验的一手来源。
- [ ] **有没有标日期/版本**：Agent 领域半年前的"最佳实践"可能已过时。没有日期、且讲的是具体 API 用法的教程，要格外警惕。
- [ ] **给结论还给权衡吗**：只吹"某方案吊打一切"、不谈代价和适用边界的，多半是营销或半懂。好资料一定会讲"什么时候不该用"。
- [ ] **能不能跑**：讲代码/框架的资料，判据是"照着能不能跑通"。跑不通又不给版本信息的，直接跳过。
- [ ] **它解决了什么老方案解决不了的问题**：面对"新名词"，答不上这一句就先放着——很多只是旧概念换皮。

> **一句话原则**：**一手 > 二手，近期 > 陈旧，能跑 > 空谈，讲权衡 > 只吹优点。** 四条里踩雷两条以上的资料，基本可以不看。

## A.10 英文一手资料怎么读（给英文吃力的人）

本附录的一手资料多为英文，但"英文不好"不该成为只读二手转述的借口。按下面三步，能用较低的英文成本吃到一手内容的核心：

- **先中后英**：先用本书正文或中文讲解建立概念，再回看英文原文——带着已知框架读，生词也能猜个八九不离十。
- **只读高价值段落**：论文读 Abstract + 结论图表，博客读小标题 + 每段首句 + 加粗处，先抓主干再决定要不要细读，不必逐字。
- **建自己的术语对照表**：把反复出现的英文术语（agentic、handoff、grounding、guardrail 等）记进附录 C 那张速查表，读第二篇同类资料时就顺了。

> **经验**：坚持读一手英文的最大回报不在当下，而在面试——你能直接引用 Anthropic/OpenAI 原文的措辞和判断标准，比转述"网上有人说"专业得多，也更经得起追问。

## A.11 三种"最小可行资料包"（时间有限时照抄）

不是每个人都有一个月。按你手头的时间，直接抄下面对应的最小组合，别再纠结"还有哪些没读"：

- **只有一个周末（约 6 小时）**：Anthropic《Building Effective Agents》通读一遍 + Lilian Weng 长文抓"规划/记忆/工具"三大件 + 跑通一个 smolagents 官方示例。目标是建立"Agent 是什么、由什么组成、循环怎么转"的整体直觉。
- **有两周（业余时间）**：在上面基础上加 HF Agents Course 前半程（含动手单元）+ 读透 smolagents 主循环源码 + 跑 2-3 个 GenAI_Agents 基础案例并各改一处。目标是"能徒手看懂并改动一个 Agent 主循环"。
- **面试前最后一晚**：只做两件事——重读 Anthropic 与 OpenAI 两份指南的核心观点（最常被引用），再把附录 B、C 扫一遍确保话术与术语能脱口而出。别学新东西，把已会的说利索比什么都强。

> **提醒**：这三个包是"起点"不是"终点"。跑通最小包后，再回到 A.7 的分级路线按阶段扩展；一次只推进一级，完成一级再看下一级，比一开始就想读完全部更可持续。
