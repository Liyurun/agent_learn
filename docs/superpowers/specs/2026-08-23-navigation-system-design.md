# 分层目录导航系统设计

## 目标

为手册增加两层互补导航：

1. 顶部一级菜单悬浮或聚焦时，展示该分篇下的章节入口。
2. 桌面端右侧展示当前章节的 `h3` 小节目录，并随阅读位置高亮。

顶部导航解决“去哪个章节”，右侧导航解决“当前章节看到哪里”。两者都由现有内容源自动生成，避免新增章节后手工同步。

## 顶部导航

### 数据来源

顶部菜单从 `content/book.json` 中 `toc=true` 的项目生成，以 `toc_group` 分组。分篇入口对应：

- 原理：第一篇
- 技术：第二篇
- 实践：第三篇
- 面试：第四篇
- 进阶：第五篇
- 实战：第六篇

资源入口保留为直接链接，不生成章节下拉。

### 桌面交互

- 鼠标进入一级菜单或下拉面板时展开。
- 键盘聚焦一级菜单或下拉项时展开。
- 鼠标离开整个菜单区域后关闭。
- `Escape` 关闭并把焦点返回一级入口。
- 一级入口点击仍跳到对应分篇页。
- 下拉项显示章节编号和标题，点击后跳到章节锚点。
- 当前分篇入口与当前章节项随滚动高亮。

### 移动交互

宽度不超过 768px 时不依赖 hover。

- 顶栏显示“目录”按钮。
- 点击后展开分篇列表。
- 点击分篇名称展开或收起章节列表。
- 点击章节后关闭移动目录并跳转。
- 点击菜单外或按 `Escape` 关闭。

## 右侧当前章目录

### 内容提取

构建器为所有正文章节和 Lab 中的 `h3` 生成稳定锚点。规则：

- 已有 `id` 原样保留。
- 没有 `id` 时，以章节 ID 加小节序号生成，如 `ch10-section-01`。
- 锚点与标题顺序写入页面内的导航数据。
- 构建器重复运行时锚点不漂移。

侧栏只显示当前 `section.chapter` 的 `h3`，不显示 `h4`，避免目录过深。

### 桌面布局

- 视口宽度大于 1280px 时显示在正文右侧。
- 使用 `position: fixed` 或等效 sticky 布局，不改变正文现有最大宽度。
- 标题过长时单行截断，并通过 `title` 展示完整标题。
- 当前小节高亮，章节切换时目录内容同步切换。
- 点击小节平滑滚动，并避开顶部固定导航。

### 中小屏幕

- 769–1280px 隐藏右侧栏，避免遮挡正文。
- 不超过 768px 时，在页面边缘提供“本章目录”按钮。
- 按钮展开当前章节小节列表；选择后关闭。
- 当前章节没有 `h3` 时不显示按钮。

## 状态与滚动

- 使用 `IntersectionObserver` 观察章节和小节。
- 当前章节优先选择最接近顶栏下方的可见章节。
- 当前小节高亮采用同一观察器或基于滚动位置计算。
- 页面通过锚点直接打开时，初始化目录和高亮必须正确。
- 浏览器不支持 `IntersectionObserver` 时，使用节流后的滚动位置计算降级。

## 构建边界

- `content/book.json` 是顶部章节菜单唯一数据源。
- `tools/handbook_build.py` 负责生成顶部菜单 HTML，并给 `h3` 注入稳定 ID。
- `templates/handbook.html` 保存导航占位符、CSS、DOM 容器与运行时交互。
- 内容 Markdown 不需要手工维护侧栏目录。
- 生成后的 `agent-learning-handbook.html` 不直接编辑。

## PDF

打印和 PDF 导出隐藏：

- 顶部下拉面板。
- 移动目录面板及按钮。
- 右侧当前章导航。

正文、章节标题和注入的小节锚点继续保留。

## 无障碍

- 一级菜单使用按钮或带 `aria-haspopup` 的链接。
- 下拉面板与触发器通过 `aria-controls` 关联。
- 展开状态写入 `aria-expanded`。
- 移动菜单和本章目录可通过键盘操作。
- 焦点样式清晰，隐藏菜单不能被 Tab 聚焦。

## 测试

- 清单中的所有 `toc=true` 项都出现在对应顶部菜单。
- 新增章节后顶部菜单自动出现该项。
- 构建两次得到相同的小节 ID。
- 所有小节链接均指向唯一锚点。
- 顶部 hover/focus、`Escape`、移动点击和外部关闭逻辑存在。
- 右侧目录只显示当前章 `h3`。
- 原有主题菜单、字号、章末学习标记和顶栏高亮不受影响。
- PDF 预处理隐藏全部导航辅助 UI。

## 验收标准

1. 桌面端悬浮“原理”等菜单可以看到对应章节并直接跳转。
2. 当前分篇和当前章节在顶部菜单中高亮。
3. 宽屏右侧显示当前章小节并随滚动高亮。
4. 移动端可以点击打开全书目录和本章目录。
5. 新增章节只修改 Markdown 和 `book.json`，顶部菜单自动更新。
6. 测试、源校验、HTML 构建、最终校验和 PDF 导出全部通过。

## 非目标

- 不增加左侧全书常驻栏。
- 不把 `h4` 加入右侧目录。
- 不修改章节正文结构或标题文案。
- 不引入前端框架或第三方导航组件。
