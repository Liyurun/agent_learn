# 四主题菜单与顶栏精简设计

## 目标

删除顶栏动态生成的“已学 0/24”按钮，保留各章末尾“标记学完”及其本地存储；将现有深浅色切换按钮升级为可明确选择的四主题下拉菜单。

## 主题

| ID | 名称 | 定位 |
|---|---|---|
| `paper` | 纸张白 | 当前浅色基线，适合打印与日常阅读 |
| `warm` | 暖米色 | 低冷白、偏纸质阅读 |
| `mist` | 雾蓝色 | 冷静的浅蓝灰技术主题 |
| `dark` | 深夜黑 | 当前深色基线 |

每个主题定义 `--bg`、`--bg2`、`--ink`、`--muted`、`--rule`、`--accent`、`--accent2`、`--dark`、`--dark2` 和顶栏半透明背景。封面图片保留，但遮罩随主题适配。

## 交互

- 顶栏显示“◐ 主题”按钮。
- 点击按钮打开带四个单选项的菜单，当前项显示选中状态。
- 选择主题后立即应用并写入 `localStorage` 的 `ah-theme`。
- 旧值 `light` 自动迁移为 `paper`，旧值 `dark` 保持有效，非法值回退为 `paper`。
- 点击菜单外、按 `Escape` 或选择主题后关闭菜单。
- 按钮维护 `aria-expanded`，菜单使用 `role="menu"`，选项使用 `role="menuitemradio"` 与 `aria-checked`。
- 图表重绘接口继续接收“是否深色”；仅 `dark` 传 `true`。

## 学习进度

- 删除 `.lg-counter` 样式。
- 删除 `counterEl`、`refreshCounter()`、计数按钮创建和“跳到第一个未学章节”逻辑。
- 保留 `ah-read-chapters`、章末按钮、已学样式及状态切换。

## PDF

PDF 导出前强制设置 `data-theme="paper"`，关闭主题菜单，并触发图表浅色重绘，避免用户本地主题影响成品。

## 测试与验收

- 模板包含四个主题选项，不再保留旧二元切换文案。
- `learner-guide.js` 不再包含 `lg-counter` 或“已学 x/y”顶栏逻辑。
- 章末 `.lg-read-btn` 与 `ah-read-chapters` 仍存在。
- 主题选择持久化、旧值迁移、外部点击和 `Escape` 关闭逻辑存在。
- PDF 导出强制纸张白。
- Python 与 Node 测试、源文件校验、HTML 构建、最终校验和 PDF 导出全部通过。

## 非目标

- 不删除章末“标记学完”。
- 不改变封面图片。
- 不为不同主题保存不同学习进度。
- 不新增远程主题资源。
